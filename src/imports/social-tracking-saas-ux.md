Prompt profesional para Figma (UX completo)

Diseña la interfaz completa de una aplicación web tipo SaaS llamada:

Sistema de Seguimiento de Proyección Social

La plataforma será utilizada por docentes universitarios y administradores para reportar avances semanales de proyectos, actividades y convenios, y subir evidencias de cumplimiento.

El sistema debe permitir:

login de usuarios

reporte semanal de avances

carga de evidencias mediante links o archivos

revisión y validación por administradores

visualización de métricas y reportes

El diseño debe ser moderno, profesional, claro y orientado a dashboards de gestión académica.

Usar:

estilo SaaS moderno

diseño limpio

tarjetas informativas

tablas de datos

gráficos

sidebar de navegación

topbar con perfil y notificaciones

colores institucionales (azul, blanco, gris)
